# Cybersecurity Signal

A responsive, static GitHub Pages site publishing calm, source-led explainers on emerging cyber threats, online advertising abuse, PHP security, AI prompt injection and practical defence.

## Live site
https://jazblue.github.io/cybersecurity-signal/

## Files
- `index.html` — main page and explainers
- `styles.css` — responsive dark/light design
- `script.js` — small progressive enhancement (footer year)

## Publish
GitHub Pages is configured to publish from the `main` branch root. No build step, server, PHP runtime, database, analytics or third-party JavaScript dependencies are required.

## Editorial principles
- Distinguish confirmed research from inference.
- Link to primary research and vendor/security advisories.
- State dates and update claims when sources change.
- Explain the difference between server compromise, visitor-device compromise and AI prompt injection.
- Avoid implying that every visitor to a page or advert is affected.
- This is educational material, not incident-response advice.
